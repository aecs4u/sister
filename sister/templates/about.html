Informazioni su SISTER

Che cos'è SISTER?

SISTER è un servizio di estrazione automatica di dati catastali che interroga il catasto italiano (Agenzia delle Entrate — portale SISTER) tramite automazione del browser.

Offre:

  • API REST — endpoint HTTP basati su FastAPI per l'accesso programmatico
  • CLI — strumento da riga di comando sister con oltre 16 tipi di query
  • Interfaccia web — questa dashboard per le query interattive e la consultazione dei risultati
